# NEOKOSMOS

**https://quietoak.github.io/NeokosmosWiki/**

> The remnants of Atlantis lie scattered like forgotten dreams; barbarian hordes roam the untamed wilderness, their fierce spirits unyielding. Amidst the ruins of bygone glory, whispers abound of ancient magic—relics of a time when gods walked among mortals and wonders were wrought with but a word.
>
> In this dark era of exploration and war, where the line between myth and reality blurs with each passing day, the remnants of civilization huddle behind thick walls—save those brave few adventurers.  
> It is the time between the Age of Atlantis and the Age of Crushing Ice, where dreams of forgotten glory may be reclaimed and the world restored by one brave enough.
>
> **It is the age of high adventure!**

Neokosmos is a dark fantasy adventure setting inspired by Robert E. Howard’s Hyperborea.

**Content warning**: This setting contains mature material intended for adult audiences only. It explores dark themes, intense violence, occult horror, and morally complex situations.

## About This Project

The Neokosmos Wiki is an ongoing worldbuilding project that catalogs:

- Histories and timelines  
- Races and peoples  
- Magic system  
- Characters and factions  
- Geography and realms  
- Artifacts and relics  
- Cultures, religions, and armies  

### This repository includes:
- A fully custom-styled TiddlyWiki  
- HTML formatting in the “Neokosmos Style”  
- Image & media library  
- Template tiddlers and JSON bundles  
- Import/export files for expansion  

### The “Neokosmos Style” features:
- Deep obsidian backgrounds  
- Soft parchment-gold text  
- Warm ember highlights  
- Garamond / Palatino serif typography  
- Atmospheric borders, mists, and glows  
- Clean index pages and organized navigation  

### How to Contribute

Access the wiki using either:
The hosted version (recommended), or
A local copy by downloading or cloning the repository and opening index.html in a modern browser.

Make your edits directly inside the TiddlyWiki interface as usual.
When finished, export only the tiddlers you changed:
Use TiddlyWiki’s export tools to save the modified tiddlers as files.

Submit your exported tiddlers by either:
Posting them in the Discord (link below), or
Uploading them via a GitHub issue.
